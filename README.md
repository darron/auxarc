# Magazine-carrier hinge fix

**We copied the working wing’s hinge onto the magazine carrier.**

- **Problem:** plastic between the carrier’s hinge teeth overlaps the holster in the model.
- **Change:** copied the wing’s teeth, gaps, and nearby neck onto the carrier body.
- **Worked:** the carrier now seats; the filament pin starts entering the last section.
- **Still checking:** it is tight. The pin has **not been confirmed all the way through**.
